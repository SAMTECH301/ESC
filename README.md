# ESC
This project involved the design of a compact, high-current  Electronic Speed Controller (ESC) optimized for multirotor UAV applications. The PCB employs a single-sided copper strip overcurrent architecture to efficiently handle large motor currents while remaining within standard manufacturing constraints.

The power stage is built around onsemi NTMFS5C430NLT1G MOSFETs (200A, 40V, 1.xn--4m-fcc), enabling low-loss switching in a 40.5 × 49.3 mm compact form factor. Gate-drive voltage optimization was applied to reduce MOSFET on-resistance and improve overall efficiency, with performance validated through practical testing.

This project demonstrates hands-on expertise in ESC power stage design, high-current PCB layout, and UAV-grade power electronics.
